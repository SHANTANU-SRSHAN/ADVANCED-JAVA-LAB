

## 📂 Projects

### 1. 📝 Student Registration Form

**Folder:** `Exp_01_Student_Registration_Form`

A Java-based student registration form that demonstrates how to create a basic graphical user interface and collect user information.

**Key Concepts:**
- Java GUI
- Forms and input fields
- Buttons and event handling
- User input processing

**Purpose:**  
To understand the basics of GUI-based Java applications and event-driven programming.

---

### 2. 🧮 Calculator

**Folder:** `Exp_02_Calculator`

A simple calculator application that performs basic arithmetic operations through a graphical interface.

**Key Concepts:**
- Java GUI
- Event handling
- Arithmetic operations
- User input

**Purpose:**  
To learn how GUI components interact with Java logic and how button events are handled.

---

### 3. 🗄️ MySQL Connection using JDBC

**Folder:** `Exp_03_Mysql_Connect(JDBC)/jdbc`

This project demonstrates how a Java application connects to a **MySQL database using JDBC** and communicates with the database through SQL.

**Key Concepts:**
- JDBC
- MySQL
- Database connection
- SQL queries
- `Connection`
- `Statement` / `PreparedStatement`
- `ResultSet`

**Purpose:**  
To understand how Java applications communicate with relational databases.

**Requirements:**
- JDK
- MySQL Server
- MySQL JDBC Driver

---

### 4. 🌐 Server-Client Basics

**Folder:** `Exp_04_Server_Client_Basics`

A basic networking project demonstrating communication between a **client and server** using Java networking concepts.

**Key Concepts:**
- Client-server architecture
- Sockets
- Server sockets
- Input/output streams
- Network communication

**How it works:**

```text
Client → Connection → Server
Client ← Response   ← Server
```

**Purpose:**  
To understand the fundamentals of network communication and client-server applications.

---

### 5. 🔗 Java RMI

**Folder:** `Exp_05_RMI`

This project demonstrates **Remote Method Invocation (RMI)**, which allows a Java program to call methods of an object running in another JVM.

**Key Concepts:**
- Java RMI
- Remote interface
- Remote object
- RMI Registry
- Client-server communication

**Purpose:**  
To understand how distributed Java applications communicate with remote objects.

**Basic flow:**

```text
Client → RMI Registry → Remote Object → Server
```

---

### 6. 🐱 Apache Tomcat

**Folder:** `Exp_06_Apache_Tomcat/apache-tomcat-11.0.25`

This project contains the Apache Tomcat environment used to run Java web applications.

**Key Concepts:**
- Apache Tomcat
- Servlet container
- Web application deployment
- HTTP request/response
- Java web server

**Purpose:**  
To understand how Java web applications are deployed and executed using a servlet container.

---

### 7. 🌐 Servlet & JSP

**Folder:** `Exp_06_Servlet,Jsp/servlet`

A Java web application project demonstrating **Servlet and JSP** technologies for creating dynamic web applications.

**Key Concepts:**
- Java Servlets
- JSP
- HTTP requests and responses
- Request handling
- Server-side processing
- Tomcat deployment

**Basic flow:**

```text
Browser
   ↓
Servlet
   ↓
Java Logic
   ↓
JSP
   ↓
Browser
```

**Purpose:**  
To learn how Java is used for server-side web development and dynamic web pages.

---

### 8. 🛒 ShopSphere

**Folder:** `ShopSphere`

ShopSphere is the main application-oriented project in this repository. It represents an **e-commerce/online shopping application** and brings together concepts learned from the previous experiments.

**Main Areas:**
- Online shopping workflow
- Product-related functionality
- Web application development
- Backend processing
- Database interaction

**Purpose:**  
To apply Advanced Java and web-development concepts in a larger, real-world style application.

### Requirements

Install the required software depending on the project:

- **JDK**
- **MySQL** — for JDBC projects
- **MySQL JDBC Driver**
- **Apache Tomcat 11** — for Servlet/JSP projects
- Java IDE such as IntelliJ IDEA, Eclipse, or NetBeans

### Running Projects

Open the required project in your Java IDE and run the appropriate Java class.

For JDBC projects, configure the MySQL:

```text
Database URL
Username
Password
```

For Servlet/JSP projects, deploy the application on Tomcat and access it through:

```text
http://localhost:8080/
```
