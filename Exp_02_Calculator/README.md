# Calculator (Swing MVC)

## Aim
To create a simple calculator application using Java Swing and the MVC design pattern.

## Features
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Graphical user interface using Java Swing

## Technologies
Java, Swing, MVC.

## How to Run
Open this folder in your Java IDE. Compile the source files from the appropriate source root, then run the main class. If package declarations are used, follow the package structure when compiling and running.
