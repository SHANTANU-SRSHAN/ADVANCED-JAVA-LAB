# Server Client Basics (Java Sockets)

## Aim
To demonstrate client-server communication using Java TCP sockets.

## Technologies
Java, `ServerSocket`, `Socket`, TCP networking.

## How to Run
Open two terminals in this folder and compile the files:

```bash
javac server.java
javac client.java
```

Start the server in the first terminal:

```bash
java server
```

Then start the client in the second terminal:

```bash
java client
```
